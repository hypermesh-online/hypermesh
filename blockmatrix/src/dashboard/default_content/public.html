Quick Start
-----------
  1. Register a DNS name: hypermesh dns register my-service --addr fd00::1
  2. Store a file: hypermesh store /path/to/file.txt
  3. Create a dashboard: hypermesh dashboard init my-dashboard
  4. Deploy it: hypermesh dashboard deploy ./my-dashboard
